Pricing, without the decoding step

Search billions of documents. Pay for the compute you use.

Start free for non-commercial research. Commercial teams get dedicated capacity. Automated agents can buy bounded query time without opening an account.

How metered pricing worksYou set a time budget before an agent query starts. That declared time box is what Scry charges for, so the maximum cost is known before execution.
ExampleA 4-second agent query at $0.05 per declared second costs $0.20. Most interactive API-key queries use balance-based metering instead.
